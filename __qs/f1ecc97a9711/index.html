01.2 METHODEN

E-Mail, SMS und QR-Codes. Die Wege der Manipulation.

VECTOR: SMS_PHISHING
MOBILE SECURITY // EXPLOIT ANALYSIS

SMISHING

DER DIREKTE DRAHT ZUM ENDGERÄT

SMS-Betrug nutzt unser blindes Vertrauen in das Smartphone. Nachrichten über nicht zustellbare Pakete drängen uns zum schnellen Handeln. Da URLs auf dem Handy oft gekürzt werden, ist die Täuschung hier am effektivsten.

ATTACK_TYPE SOCIAL ENGINEERING
MAIN_TARGET MOBILE USER
URL_ANALYSIS: MALICIOUS_MATCH
DOMAIN ARCHITECTURE // TYPOSQUATTING

PHISHING

DIE ARCHITEKTUR EINER FÄLSCHUNG

Achten Sie auf die Domain. Hacker nutzen Typosquatting – sie registrieren Adressen, die dem Original zum Verwechseln ähnlich sehen. Ein einziger Buchstabe Unterschied entscheidet über Ihren Frieden.

METHOD URL SPOOFING
RISK_LEVEL CRITICAL (HIGH)
PHYSICAL_SECURITY // QUISHING

QR-CODES

DER BLINDE KLICK IM ALLTAG

QR-Codes sind Vertrauensanker im Alltag. Doch hinter dem Muster kann ein schädlicher Befehl lauern. Angreifer überkleben echte Codes an Parkautomaten oder in Restaurants, um Sie unbemerkt auf Phishing-Seiten zu leiten. Scannen ist das neue Klicken.
